# ♟️ ჭადრაკის პაზლები ♟️
ეს გუნდური პროექტი წარმოადგენს სამი სტუდენტის მიერ შექმნილ აპლიკაციას, სადაც მოთამაშეეებს შუეძლიათ ამოხსნან სხვადასხვა სირთულის ჭადრაკის პაზლი და აიმაღლონ რეიტინგი.
---------------------
მოთამაშეს შეუძლია:
• შეიყვანოს მისთვის სასურველი Username (მომხმარებლის სახელი);
• ეს Username დაემატება ბაზაში და მასთან აპლიკაციის გამოყენების განმავლობაში ასოცირებული იქნება მოთამაშის: სახელი, რეიტინგი და ამოხსნილი პაზლების რაოდენობა;
• ნახოს ნებისმიერი პაზლის ამოხსნა ან გადავიდეს შემდეგ პაზლზე ამოხსნის გარეშე;
• შეუძლია წაშალოს საკუთარი მომხმარებლის ანგარიში და მასთან ასოცირებული ყველა ინფორმაცია;
• შეუძლია შეიყვანოს სხვა მომხმარებლის სახელი (Username) წინას წაშლის გარეშე.
---------------------
ჭადრაკის პაზლები წამოღებულია ცალკეული ბაზიდან. ცალკე ბაზა იქმენა მომხმარებლების სამართავადაც.
---------------------
გუნდის წევრები და მათი როლები:
ნიკოლოზ კურტანიძე - იმუშავა ჭადრაკის ლოგიკაზე და ფუნქციონალზე.
ნიკოლოზ ფეიქრიშვილი - იმუშავა აპლიკაციის UI დიზაინის შექმნაზე.
თემურ ხვედელიძე - იმუშავა ბაზებზე და მათ სწორად გამართულობაზე.
